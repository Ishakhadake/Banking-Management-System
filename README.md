# 🏦 Banking Management System

A Java-based Banking Management System developed using Core Java, Java Swing, MySQL, and JDBC. It is a desktop application designed to simplify banking operations through a graphical user interface.

## 📌 Overview

The Banking Management System is designed to manage basic banking activities digitally. It allows customers to create accounts, register, log in, deposit money, withdraw money, transfer funds, check balances, and view transaction history.

This project demonstrates the practical use of Java programming, Object-Oriented Programming, GUI development, and database connectivity.

## 🎯 Objectives

- Simplify basic banking operations.
- Manage customer account information.
- Maintain transaction records.
- Provide an interactive GUI.
- Understand Java and database integration.

## 🚀 Features

1. **Account Creation:** Create new bank accounts.
2. **Customer Registration:** Register new customers.
3. **Login Authentication:** Access registered accounts.
4. **Forgot Password:** Recover account access.
5. **Dashboard:** Access banking services.
6. **Check Balance:** View available balance.
7. **Deposit Money:** Add money to an account.
8. **Withdraw Money:** Withdraw money from an account.
9. **Transfer Money:** Transfer funds between accounts.
10. **Transaction History:** View previous transactions.

## ⚙️ How to Run

1. Clone the GitHub repository.
2. Open the project in Eclipse IDE.
3. Configure the MySQL database.
4. Add MySQL JDBC Connector.
5. Update database connection details.
6. Run `BankManagementSystem.java`.
